# Simple_Dashboard_using_Excel


## Overview

This project is an Excel-based Chocolate Sales Dashboard designed to analyze and visualize chocolate product performance, sales trends, profit insights, and customer/business patterns through interactive charts, KPIs, and data summaries.

The dashboard helps users quickly understand:
* Total Sales Performance
* Product Category Trends
* Regional/Customer Insights
  
## Objectives
* Track chocolate sales performance
* Compare product categories
* Identify top-performing products
* Support data-driven business decisions
  
## Tools & Skills Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Cleaning
* Dashboard Design

## How to Use
1. Download the Excel file from this repository

3. Enable editing if prompted
